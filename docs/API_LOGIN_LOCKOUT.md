# สเปก API: บัญชีถูกล็อกจากการกรอก PIN ผิด (U7)

เอกสารนี้กำหนดรูปแบบ response ของ `POST /api/auth/login` เมื่อบัญชีร้านค้าถูกล็อกชั่วคราว
ฝั่ง Frontend (Task30) ทำเสร็จแล้วและอ่านค่าตามรูปแบบนี้ ฝั่ง Backend ต้องส่งให้ตรงกันจึงจะใช้งานได้

## Response เมื่อบัญชีถูกล็อก

```http
HTTP/1.1 423 Locked
Content-Type: application/json
```

```json
{
  "success": false,
  "locked": true,
  "retryAfterSeconds": 300,
  "lockedUntil": "2026-11-14T16:30:00.000Z",
  "message": "บัญชีถูกล็อกชั่วคราว"
}
```

| ฟิลด์ | ชนิดข้อมูล | จำเป็น | คำอธิบาย |
|---|---|---|---|
| `success` | boolean | ใช่ | เป็น `false` เสมอ |
| `locked` | boolean | ใช่ | เป็น `true` เมื่อบัญชีถูกล็อก |
| `retryAfterSeconds` | integer | อย่างน้อย 1 ใน 2 | จำนวนวินาทีที่เหลือก่อนปลดล็อก |
| `lockedUntil` | string (ISO 8601) | อย่างน้อย 1 ใน 2 | เวลาที่ปลดล็อก |
| `message` | string | ไม่ | ข้อความสำหรับแสดงผล |

- ควรส่ง `retryAfterSeconds` มาด้วยเสมอ เพราะไม่ขึ้นกับนาฬิกาในเครื่องผู้ใช้ ถ้าส่งมาทั้งคู่ Frontend จะใช้ `retryAfterSeconds` ก่อน
- รองรับ header `Retry-After` (วินาที) เป็นทางเลือกสำรองด้วย
- Frontend จำกัดเวลาล็อกที่แสดงไว้ไม่เกิน 24 ชั่วโมง

## สิ่งที่ Frontend ทำตาม response

| กรณี | การแสดงผล |
|---|---|
| ได้ 423 พร้อมเวลาปลดล็อก | กล่อง "บัญชีถูกล็อกชั่วคราว" + นับถอยหลัง (นาที:วินาที) ปิดช่อง PIN และปุ่ม Login จนหมดเวลา แล้วปลดล็อกอัตโนมัติ |
| ได้ 423 แต่ไม่มีเวลาปลดล็อก | ข้อความ "บัญชีถูกล็อกชั่วคราว กรุณาลองใหม่ภายหลัง" (ไม่นับถอยหลัง) |
| เชื่อมต่อเซิร์ฟเวอร์ไม่ได้ / 5xx | ข้อความ "เชื่อมต่อเซิร์ฟเวอร์ไม่ได้ / เกิดข้อผิดพลาดที่เซิร์ฟเวอร์ กรุณาลองใหม่ภายหลัง" |
| 401 PIN ผิด (ยังไม่ล็อก) | แสดง `message` จาก server ตามเดิม |

Frontend เก็บเวลาปลดล็อกแยกตามเบอร์โทรใน `localStorage` (key `hiwkhaw_login_locks`) รีเฟรชหน้าแล้วยังนับถอยหลังต่อ
แต่**การล็อกจริงต้องบังคับที่ Backend** เพราะผู้ใช้ล้างข้อมูลเบราว์เซอร์ได้

## ข้อกำหนดด้านความปลอดภัย

- ห้ามส่งจำนวนครั้งที่เหลือก่อนถูกล็อก หรือข้อมูลที่ช่วยเดา PIN (เช่น ผิดหลักไหน)
- ข้อความ 401 ควรเป็นข้อความกลาง ไม่แยกว่า "ไม่พบเบอร์" หรือ "PIN ผิด" (ป้องกันการเดาว่าเบอร์ไหนมีบัญชี)
- นับครั้งที่ผิดและล็อกตามเบอร์โทร (บัญชี) ที่ฝั่ง Backend

## ไฟล์ Frontend ที่เกี่ยวข้อง

- `client/src/services/api.js`: `loginVendor()` และ `LoginError`
- `client/src/hooks/useLoginLock.js`: นับถอยหลังและเก็บเวลาปลดล็อก
- `client/src/components/VendorLoginModal.jsx`: หน้าจอ Login
