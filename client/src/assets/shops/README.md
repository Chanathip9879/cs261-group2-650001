# รูปหน้าปกร้าน

วางรูปหน้าปกของแต่ละร้านไว้ในโฟลเดอร์นี้ แล้วหน้าเว็บจะใช้รูปนั้นแทนรูปตัวอย่างตามหมวดอาหารโดยอัตโนมัติ
(ทั้งการ์ดหน้าแรก หน้ารายละเอียดร้าน หน้าร้านโปรด และหน้าเขียนรีวิว) ไม่ต้องแก้โค้ด

## วิธีเพิ่ม/เปลี่ยนรูป

1. ดูรหัสร้านจากลิงก์หน้าร้าน เช่น `http://localhost:3000/#/shop/shop-test-01` → รหัสคือ `shop-test-01`
2. ตั้งชื่อไฟล์เป็น **รหัสร้าน** เช่น `shop-test-01.jpg`
3. วางไฟล์ในโฟลเดอร์นี้ (`client/src/assets/shops/`) — ถ้าจะเปลี่ยนรูป ให้เขียนทับไฟล์เดิม
4. commit ไฟล์รูป แล้วเปิด PR ตามปกติ

ร้านที่ยังไม่มีไฟล์รูป จะใช้รูปตัวอย่างตามหมวดอาหารเหมือนเดิม

## ข้อกำหนดของรูป

| หัวข้อ | ข้อกำหนด |
|---|---|
| นามสกุล | `.jpg`, `.jpeg`, `.png` หรือ `.webp` |
| ขนาดภาพ | แนวนอน ประมาณ 800×450 px (สัดส่วน 16:9) |
| ขนาดไฟล์ | ไม่เกิน 200 KB ต่อรูป (ย่อก่อนใส่ เช่น ใช้ squoosh.app) |
| ชื่อไฟล์ | ตรงกับรหัสร้านทุกตัวอักษร ตัวพิมพ์เล็ก ไม่มีช่องว่าง |
| ลิขสิทธิ์ | ใช้รูปที่ถ่ายเองหรือได้รับอนุญาตจากร้านเท่านั้น ห้ามใช้รูปจากเว็บอื่น |

## หมายเหตุ

- โค้ดที่อ่านโฟลเดอร์นี้อยู่ที่ `getShopImage()` ใน `client/src/utils/shopDisplay.js`
- ถ้าในอนาคตมีระบบให้แม่ค้าอัปโหลดรูปเอง ควรให้รูปที่อัปโหลดมาก่อน แล้วใช้รูปในโฟลเดอร์นี้เป็นรูปสำรอง
